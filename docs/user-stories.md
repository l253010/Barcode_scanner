# User Stories

## 1) Barcode Generation from Manual Input
**As a User,** I want to enter a 6-digit numeric code into the application **so that** I can generate a corresponding barcode.

## 2) Input Validation and Leading Zero Preservation
**As a User,** I want the system to validate my input to ensure it only accepts valid 6-digit numeric codes and correctly preserves leading zeros (for example, `001234`).

## 3) Barcode Display
**As a User,** I want to view the generated barcode clearly on the screen.

## 4) Live Camera Scanning
**As a User,** I want to use my PC camera to scan a barcode **so that** the system can automatically decode it back into the original 6-digit code.

## 5) Image Upload Scanning
**As a User,** I want to upload an image file containing a barcode **so that** the system can read and decode it when a live camera scan is not possible.
