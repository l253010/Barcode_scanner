## 🚀 Project Overview
This project focuses on building a barcode scanner using C++ and supporting libraries.  
It is designed to demonstrate practical software engineering concepts while solving a real-world scanning use case.

## ✨ Highlights
- Built in **C++**
- Focused on **barcode detection and scanning flow**
- Created as a **team project** for Semester 3 ISE

## 🧩 Tech Stack
- **Language:** C++
- **Libraries:** C++ ecosystem libraries used for scanner implementation
- **Environment:** Desktop development workflow

## 🔄 CI/CD Pipeline
This project uses **GitHub Actions** for continuous integration. The workflow in `.github/workflows/ci.yml` runs automatically on every push and pull request to `main`:

- Runs on **Windows** (`windows-latest`)
- Builds the project and checks for syntax errors
- A pull request should only be merged when the check passes
